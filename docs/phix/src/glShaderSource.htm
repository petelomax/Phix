glShaderSource

Definition: include theGUI.e -- (or pGUI.e and opengl.e)

glShaderSource(integer shader, string source)
Description: Sets/replaces the source code in a shader object.

shader: a result from glCreateShader() whose source code is to be specified/replaced.
source: the source code to be loaded into the shader.
pwa/p2js: Supported.
Notes: WebGL expects a single string, whereas the C API accepts a count and arrays of strings and their lengths or NULL if null-terminated, which lets (or from your current perspective would let) you combine text blocks like version tags and main code, so when porting such over-engineered C code you may need to bolt them together into a single string, and simply bin any silly arrays of lengths.

Any source code previously stored in the shader object is completely replaced.
The source code string is not scanned or parsed at this time, it is simply copied into the specified shader object.
glCompileShader() [as wrapped for theGUI] automatically checks for errors, so you don't have to.
See Also: glCreateShader, glCompileShader, glDeleteShader
