glBindVertexArray

Definition: include theGUI.e -- (or pGUI.e and opengl.e)

glBindVertexArray(integer vao)
Description: bind a vertex array object

vao: Specifies the name of a vertex array, from glCreateVertexArray(), or NULL to unbind.
pwa/p2js: Supported.
Errors: GL_INVALID_OPERATION is generated if array is not zero or the name of a vertex array object previously returned from a call to glCreateVertexArray().
See Also: W, X, glCreateVertexArray, Z
