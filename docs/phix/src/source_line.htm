source_line

Definition: integer i = source_line()
Description: source_line() is a function built-in to the interpreter/compiler/transpiler.
It is replaced by the source code line, which can be useful for diagnostic purposes.
pwa/p2js: Supported, however it may yield a post-transpiled src.js line number rather than the original src.e one. The latter is in fact achieved via p2js.exw/fix_source_lines() but currently only for theGUI.e/js, in due time that may also be applied to everything else. Which one is actually more helpful remains debateable. When unsure, the final src.js files (always) contain literal constants, search them to remove all doubt. Obviously when I say src.js I am implicitly including any main.htm file that also contains JavaScript. Apparently, as almost always, it is the most deceptively simple things that promise the most grief.
Comments: The call to source_line() costs nothing, except an unnamed symtab entry for the new literal constant.
It is optimized at compile-time into the appropriate integer, and only emits a load immediate literal.
Example: 
    ?source_line() -- displays 1, or whatever
    log_some_event("something",source_line())
Implementation: Optimised away as above - search for T_source_line in the compiler/transpiler source code for more details.
