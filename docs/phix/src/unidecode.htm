unidecode

Definition: include builtins\unidecode.e

string res = unidecode(string utf8)
Description: Convert unicode into simplified ASCII, primarily for sorting and text search matching.
Unrecognised/unhandled characters and multiple consecutive spaces are simply squished away,
and in fact most if not quite all wholly non-latin inputs may well yield an empty string.
For case-insensitive behaviour, lower(res) [that is, rather than the input utf8].

Based on https://github.com/thecoderok/Unidecode.NET/blob/master/src/Unidecoder.cs but
reduced to single character conversions only, so main table is 1/20th original size (15K vs 300K).
A scan of 10M real-world filenames (from Linux kernel sources, Windows Sysinternals, and
public GitHub repos) shows this approach covers >99.8% of non-ASCII filename characters
- but it will no doubt be much less than that for file contents, and be warned that figure may
drop to say 85% (there aren't any equivalent studies that I could find) for things like YouTube,
since some users are deliberately trying to avoid any machine-capable pattern matching.
In the GitHub repository you can find a full-on version in unidecoder-decodemap.e (which
ended up 441K) and unidecode2.e but they're not part of the standard distro.

You may also want some leetcode handling such as txt = substitute_all(txt,"30@$","eoas"),
but that would be heavily dependent on precisely where the input data came from.

For an example of use, see the recent files popup in demo\theGUI\gVidCut.exw
[it is quite subtle, and you'll need to download some unicode-named video files to actually see it in action.]

See also demo\theGUI\audit_unidecode.exw which showcases the immense scale of the matter by walking through the 13,056 mappings it performs, split into 51 pages with 4/8/16 chunks each - myself, I'm lost on page 3. There are probably more than a few issues, especially with underscores (=> space), doublequotes (=> backtick), and backslashes (=> forwardslash), but once you can see the mistake, it should be fairly straightforwad to tweak the table and backport changes into unidecode.e - all after initial and with final testing, of course.
