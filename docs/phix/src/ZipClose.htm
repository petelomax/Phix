ZipClose

Definition: include builtins\LiteZip.e

object hzip = ZipClose(object hzip)
Description: Closes the zip archive(s). The parameter hzip may be an atom or a sequence of them.

Terminates in error on failure (when not a valid non-null zip handle).
pwa/p2js: Not supported.
Example:
Copy 
include builtins\LiteZip.e

atom hzip = ZipCreateFile("test.zip")

hzip = ZipClose(hzip)

--or--

atom hzip1 = ZipCreateFile("part1.zip"),
     hzip2 = ZipCreateFile("part2.zip")

{hzip1,hzip2} = ZipClose({hzip1,hzip2})
See Also: ZipCreateFile
