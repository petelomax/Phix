UnzipSetBaseDir

Definition: include builtins\LiteZip.e

UnzipSetBaseDir(atom hzip, string basedir)
Description: Sets the base directory for subsequent file extraction.

hzip: the result of a successful call to UnzipOpenFile().
basedir: can be an absolute or relative directory path.

WARNING: Full paths are strongly recommended and operate in a rock-solid fashion, whereas a relative directory prepends current_dir(), which may sometimes change under your feet, and worse, `\test` is likely to be taken as `C:\test`.
Of course in many cases "wherever, man" is fine, but "just hoping" it always will be is a poor long-term strategy: you should give some thought to using the user's home directory, an app-specific directory, a system-wide temp directory, or perhaps guarantee to be in the same directory as a specific one of the files being [un]compressed.
That said, just after successfully opening "test.zip", "here" is probably fine too, except when they've downloaded to C:\Downloads but you were foolishly expecting somewhere else.

To explicitly pass full paths to the last (optional) parameter of UnzipItemToFile(), you must first invoke UnzipSetBaseDir(hzip,``) to clear any tunzip->Rootdir[], or perhaps something like `E:\` or maybe (temporarily) chdir() to that.

Terminates in error on failure (which in this case means an invalid hzip).
pwa/p2js: Not supported.
Example:
Copy 
include builtins\LiteZip.e

atom hzip = UnzipOpenFile("phix.0.7.7.1.zip")

UnzipSetBaseDir(hzip,"test")

ZIPENTRY ze = new_ZIPENTRY()
?UnzipFindItem(hzip,ze,"readme.txt") -- prints 0 (ZR_OK)
?UnzipGetFileName(ze) -- prints `test\readme.txt`

hzip = UnzipClose(hzip)
ze = free(ze)
See Also: UnzipOpenFile, ZIPENTRY, UnzipFindItem, UnzipGetFileName, UnzipClose
