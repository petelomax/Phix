glCreateVertexArray

Definition: include theGUI.e -- (or pGUI.e and opengl.e)

integer res = glCreateVertexArray()
Description: Create a vertex array object.
pwa/p2js: Supported.
Notes: glCreateVertexArray() wraps the glGenVertexArrays(n) C api, which has been renamed glCreateVertexArrays(n) in 4.5+, but using the singular form to match the WebGL api, which(/since that) creates them strictly one at a time.
See Also: glBindVertexArray, glEnableVertexAttribArray, glVertexAttribPointer, (glDeleteVertexArrays), (glIsVertexArray) - last two not yet wrapped
