libmpv

mpv is a free (as in freedom) media player for the command line.
libmpv provides a C API for embedding mpv's playback engine into other applications.
The API is licensed under ISC (legally identical to MIT but ~350 chars shorter), while mpv core is GPLv2+.
The file builtins\libmpv.e (not an autoinclude) contains a fairly rudimentary wrapper for libmpv.
Note this page proudly documents ~0.0001% of everything you actually need to know
- the rest is buried on https://mpv.io/manual/master - and don't forget your shovel.
The api docs in client.h, quite understandably, refer you to the cli (command line interface) docs, which
means scant type information and you often have to guess which are options, properties, or commands.
That is perhaps an unfair criticism, it is all properly organised, just not in the way I'd prefer it to be.
This page effectively replaces the client.h part of the documentation, and only that specific part.

The distro includes builtins\libmpv-2.(32|64)bit.ca25.dll which are client api version 2.5 from 19/8/2025,
the repo also contains 2.0(/ca20) versions from 24/04/2022 in case they help. Should you find or make other
useful [32&64 bit] builds let me know. Linux users are expected to build and install from source on their own.

See demo\theGUI\gVidCut.exw for example use. Windows-only at the time of writing.

Use gSetAttribute(video_canvas,`MPV_INIT`,mpv_init) to specify the output.

None of these routines are [as yet] supported by pwa/p2js.

constants

MPV_FORMAT_STRING  = 1,
MPV_FORMAT_FLAG  = 3,
MPV_FORMAT_INT  = 4,
MPV_FORMAT_DOUBLE  = 5,
MPV_ERROR_SUCCESS  = 0 -- (normally checked inside libmpv.e itself for you)

routines

object res = 
mpv_client_api_version(string rtype="")

Returns eg `2.5` by default, but can be made to return {2,5} or #00020005 via rtype of `mm` and `ulong` respectively, in case those forms are more practical for you.

integer mpv_ctx = 
mpv_create(bool bCrash=true)

By default simply crashes when anything goes wrong.
Graceful handling of a NULL result (when bCrash is false) left as an exercise...
  (which would probably involve throw/catch an exception to unwind call stack properly)
Explicitly bound via the `wid` option(see next) to the platform-specific
handle as gets passed to the mpv_init() procedure mentioned above.
Returns an index to the internal ctx_table (or null).

procedure 
mpv_set_option_string(integer ctx, string name, data)

Sets a named option. Crashes on error.
Known working name,data pairs include `wid`,sprintf(`%d`,handle), `vo`,`gpu`, `keep-open`,`yes`, `pause`,`yes|no`, `video-zoom`,`0`, `video-pan-x`,`0`, `video-pan-y`,`0`, `video-unscaled`,`no`, and `mute`,`yes|no`.

For more information about the handle needed for wid, see MPV_INIT.

procedure 
mpv_initialize(integer ctx)

Typically several options are explicitly set between mpv_create() and mpv_initialize().
Some options must be set before initialisation (wid, vo), others can be changed anytime.

string path = 
mpv_normalize_path(string raw_path)

Converts backslashes to forward slashes (Windows-safe + mpv-safe) as required by mpv.

procedure 
mpv_command_string(integer ctx, string command)

Retries every 0.1s for up to 5s before crashing on failure.
Known working commands include `cycle mute`, `cycle pause`, `frame-step`, `frame-back-step`, `loadfile "%s"`, `seek %f relative|absolute`, `set pause yes|no`, `set video-aspect 16/9`, and `set video-zoom 0`.

object res = 
mpv_get_property(integer ctx, string name, integer mpv_format=MPV_FORMAT_STRING, object dflt=`?9/0`)

Retrieves a named property as a bool, integer, floating-point, or string.
[Aside: just so you know, it actually always gets MPV_FORMAT_STRING and converts that.]
When dflt is overridden it is returned immediately on failure.
A dflt of `?9/0` retries every 0.1s for up to 5s before crashing.
Known working properties include `duration`, `pause`, and `playback-time`.
mpv_get_property_string(integer ctx, string name) -- trivial shim (as per C)
- in practice a lose/lose compared to using mpv_get_property() directly.

procedure 
mpv_set_property(integer ctx, string name, integer mpv_format, object data)

Sets a named property. Always uses mpv_set_property_string() internally. Crashes on error.
Known working examples include `volume`,MPV_FORMAT_DOUBLE,v*100, `pause`,MPV_FORMAT_FLAG,true, `video-align-y`,MPV_FORMAT_INT,-1|0, `pause`,MPV_FORMAT_STRING,`yes`, and `sub-color`,MPV_FORMAT_STRING,`#FF0000`.

integer ctx = 
mpv_terminate_destroy(integer ctx)

It is good practice to nullify things you destroy (returns NULL).
Quietly does nothing if ctx already null/was never created.

Additional bCrash flags when/where/if ever actually needed are not expected to be particularly difficult.
