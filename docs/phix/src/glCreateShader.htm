glCreateShader

Definition: include theGUI.e -- (or pGUI.e and opengl.e)

integer res = glCreateShader(integer shader_type)
Description: Creates an empty shader object intended simply to contain the source code string that defines a shader.

Five shader_types (aka the shader object's GL_SHADER_TYPE parameter) are supported:
GL_COMPUTE_SHADER - intended to run on the programmable compute processor.
GL_VERTEX_SHADER - intended to run on the programmable vertex processor.
GL_TESS_CONTROL_SHADER - intended to run on the programmable tessellation processor in the control stage.
GL_TESS_EVALUATION_SHADER - intended to run on the programmable tessellation processor in the evaluation stage.
GL_GEOMETRY_SHADER - intended to run on the programmable geometry processor.
GL_FRAGMENT_SHADER - intended to run on the programmable fragment processor.
pwa/p2js: Supported.
Notes: Like buffer and texture objects, the name space for shader objects may be shared across a set of contexts, as long as the server sides of the contexts share the same address space.
If the name space is shared across contexts, any attached objects and the data associated with those attached objects are shared as well.

Applications are responsible for providing the synchronization across API calls when objects are accessed from different execution threads.

GL_COMPUTE_SHADER is available only if the GL version is 4.3 or higher.
Errors: This function returns 0 if an error occurs creating the shader object.
GL_INVALID_ENUM is generated if shader_type is not an accepted value.
Associated Gets: glGetShaderParameter with a valid shader object and the parameter to be queried
glGetShaderInfoLog with a valid shader object
glGetShaderSource with a valid shader object
glIsShader
See Also: glAttachShader, glCompileShader, glDeleteShader, glDetachShader, glShaderSource
