gDatePick

Definition: include theGUI.e

gdx id = gDatePick(gdx calendar, [rtn value_changed=NULL,] string attributes="", dword_seq args={})
Description: Creates a date editing interface element, which can drop-down a calendar for selecting a date.

calendar: (mandatory) a gCalendar to be used in the drop-down.
value_changed: (optional) a procedure invoked when the contents change.
The handler and attributes on a gDatePick are the same as those on a gText, and distinct from a gCalendar.

Returns the identifier of the created element.
pwa/p2js: Supported.
Example: 
-- demo\theGUI\gDatePick.exw
include theGUI.e

procedure value_changed(string v)
    ?v
end procedure

integer margin = iff(gVersion(-2)=3?7:13)
gdx cal = gCalendar({2025,11,5}),
    txt = gDatePick(cal,value_changed,"VALUE=05/11/2025"),
    hbx = gVbox({txt},`==`,{{`MARGIN`,margin}}),
    dlg = gDialog(hbx,`gDatePick`,`SIZE=240x80`)
gSetAttribute(cal,`RANGE`,{{2025,11,5},{2025,11,15}})
gMainLoop(dlg)
and with the calendar drop-down manually opened:
Notes: Displays a gText with the appropriate calendar drop-down icon embedded into in, clicking on which opens the provided gCalendar in the required non-focus-grabbing manner and in the correct position, and forwards all mouse and keyboard messages to that while still open. Fundamentally the gText does not understand that the text it is holding is supposed to represent a date, and makes no attempt to push through any changes to the calendar. Equally, the gCalendar has quite literally no idea it is part of/attached to a gDatePick, and makes no attempt to modify the "parent" text when different days are selected or even when closed.

It remains entirely the responsibility of the application to make the two child controls communicate, co-operate, and play nice with each other, which needs two handlers. Leaving all that in your capable hands means you retain full control over formatting and parsing of dates ⇔ strings, for instance should you wnat to support "next thursday" that's you call rather than theGUI's job to get in your way. See gCalendar.exw for an example of the minimal code needed. [DEV]

Known issue: <Alt Down> should open the popup, and <Alt Up> / <Return> close it.
