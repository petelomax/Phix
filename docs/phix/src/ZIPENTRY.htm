The ZIPENTRY type

Definition: include builtins\LiteZip.e

ZIPENTRY ze = new_ZIPENTRY()
-- or --
bool res = ZIPENTRY(object o)
Description: This serves to define the ZIPENTRY type.

You could also call it like an ordinary function to determine whether an object is a ZIPENTRY, though I would quite strongly discourage anyone from relying on that.
pwa/p2js: Not supported.
Comments: The ZIPENTRY type is just a simple internal structure that is used to iterate over the contents of a zip file.
new_ZIPENTRY() simply returns allocate_struct(idZE), where idZE is defined as: 

global constant idZE = define_struct(`typedef struct {
                                        DWORD           Index;
                                        DWORD           Attributes;
                                        FILETIME        AccessTime, CreateTime, ModifyTime;
                                        unsigned long   CompressedSize;
                                        unsigned long   UncompressedSize;
                                        char            Name[MAX_PATH];
                                     } ZIPENTRY;`)

and you can get and set fields within it using eg ucs = get_struct_field(idZE,ze,"UncompressedSize") and set_struct_field(idZE,ze,"CompressedSize",cs) respectively, though that is fairly rarely needed, in fact only when playing about with raw memory buffers instead of the much more common disk files.

When you have finished using a ZIPENTRY variable, dispose of it using ze = free(ze).

Fun fact: the public ZIPENTRY type allows ze to be NULL, to facilitate the latter, whereas LiteZip itself quite often uses a private ZIP_ENTRY type that does not permit NULL, rather than littering up the code with assert(ze!=NULL).
Example: 
include builtins\LiteZip.e

ZIPENTRY ze = new_ZIPENTRY()
...
free(ze)
