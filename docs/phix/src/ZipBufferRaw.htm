ZipBufferRaw

Definition: include builtins\LiteZip.e

string/object res = ZipBufferRaw(object src, integer s=1, e=-1)
Description: Compress a single item. Result is a (new) binary string.

src: a memory address, or better yet a binary string, (say) from get_text(GT_WHOLE_FILE+GT_BINARY).
s,e: the start and end positions (1-based) of the (uncompressed) input, optional when string(src).

Should you have identified some portion of a binary string, rather than the whole thing, s and e can help by avoiding a slice operation for which you might not have enough memory. Note that when src is a memory address, s must be 1 as you are expected to adjust src yourself instead, aka +s-1, and therefore e (which cannot be omitted and because s==1) is the length in bytes which exactly matches the 1-based indexes as would be used on strings.

Returns a binary string or an integer error code.
Use string msg = ZipGetMessage(integer err) to obtain the human-readable version.
Personally I tend to declare res as string and rely on the typecheck for debugging - failure should be pretty rare - bad params or insufficient memory to allocate input size plus a tiny safety margin.
pwa/p2js: Not supported.
Example: 
string res = ZipBufferRaw(src)
