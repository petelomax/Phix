glSwapBuffers

Definition: include theGUI.e

glSwapBuffers(gdx canvas)
Description: Switches the front and back rendering buffers to display the newly rendered frame on the screen.
pwa/p2js: Supported, though actually ignored.
Remarks Strictly speaking, this is not part of OpenGL but theGUI, which wraps GDI32/SwapBuffers() on Windows, and will [DEV] probably need to wrap glXSwapBuffers() on Linux. It can be thought of as the logical counterpart to glMakeCurrent(), but again that's not strictly true either.

Replaces IupGLSwapBuffers(), that is when porting code from pGUI or IUP to theGUI.
See Also: glFinish
