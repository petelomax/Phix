UnzipItemToBuffer

Definition: include builtins\LiteZip.e

object res = UnzipItemToBuffer(atom hzip, object buf, integer len, ZIPENTRY ze)
Description: Extracts to a memory buffer, in a single shot or (untested) suitably sized chunks.

hzip: the result of a successful call to UnzipOpenFile().
buf: allocated memory or better yet a binary string.
len: the length of buf - will need to handle ZR_MORE when less than the uncompressed size.
ze: the recent subject of a successful UnzipGetItem() or UnzipFindItem() call.

You could allocate() buf, but then you'd probably have to peek({buf,len}) it, whereas buf=repeat(' ',len) is job done.
You can get the uncompressed size, which you'll need, from get_struct_field(idZE,ze,"UncompressedSize").

Returns ZR_OK (=0), ZR_MORE (=5), or a string error message.
pwa/p2js: Not supported.
Comments: Warning: during tesing of a since aborted attempt to get this working with a memory buffer, rather than a file, what looks for all the world like a latent bug in the C code was found: it sets ze.CompressedSize to len, which is the uncompressed size. In the File case, I found that the compressed and uncompressed sizes were already correct on entry, but leaving them like that made it stop working!

Further troubles down the line made me abandon the UnzipOpenBufferRaw() -> UnzipItemToBuffer() approach completely, and replace it with a single-shot UnzipBufferRaw(), which invokes the inflate code directly, rather than trying to fight through the LiteZip infrastructure code quirks to get there, but sadly that didn't help. All of which led me to create inflate, which is rock solid and recommended way to perform a buffer -> buffer uncompress, with this routine left in place for file -> buffer uncompress. The bottom line is that dubious line has been left in, it seems that "from file" actually needs the compressed size to be "wrong" and works fine as long as it is, but some doubts remain.
See also demo\junzip, which is the beginnings of a LiteZip-free and xxflate.e-based alternative.
Example 1:
Copy 
include builtins\LiteZip.e

atom hzip = UnzipOpenFile("phix.0.7.7.1.zip")
UnzipSetBaseDir(hzip,"test")
ZIPENTRY ze = new_ZIPENTRY()
?UnzipFindItem(hzip,ze,"readme.txt") -- prints 0 (ZR_OK)
integer l = get_struct_field(idZE,ze,"UncompressedSize")
string buf = repeat(' ',l)

?UnzipItemToBuffer(hzip,buf,l,ze)   -- prints 0 (ZR_OK)

hzip = UnzipClose(hzip)
ze = free(ze)
See Also: UnzipOpenFile, ZIPENTRY, UnzipGetItems, UnzipGetItem, UnzipClose
