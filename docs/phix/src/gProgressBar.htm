gProgressBar

Definition: include theGUI.e

gdx id = gProgressBar(string attributes="", dword_seq args={})
Description: Creates a progress bar control, with a drifting stripe pattern which grows from nothing to full width, at which point it becomes a solid green bar, and at all times displaying a completion percentage (to 2dp).

For more information on the attributes and args parameters see gSetAttributes().

Returns: the identifier of the created element.
pwa/p2js: Supported.
Example: 
-- demo\theGUI\gProgress.exw
include theGUI.e

procedure tick(gdx timer)
    gdx pbar = gGetAttribute(timer,`USER_DATA`)
    atom v = gGetAttribute(pbar,`VALUE`)
    v += 1.23
    hSetAttribute(pbar,`VALUE`,v)
    if v>=100 then
        gSetAttribute(timer,`RUN`,false)
    end if
end procedure

gdx pbar = hProgressBar(),
    hbox = gHbox({pbar},`MARGIN=10,SPACE=AROUND`),
    dlg = gDialog(hbox,`gProgress`,`SIZE=240x80`),
    timer = gTimer(tick,100,true,pbar)
gMainLoop(dlg)
Notes: Implemented in pure hll - see hProgressBar.exw if desperately curious.
An internal timer is used to update the display every 0.1s, which keeps the stripes drifting, and means there is no need to (nor much harm in) gRedraw(progress_bar) after setting an updated VALUE.
Typically an application using a progress bar will have a different independent timer, or be using an idle process.
By default it assumes the state value lies between 0 and 100, but you can also specify a range and any value within that. Note it is my choice above to stash the progress bar id in the timer's USER_DATA, not compulsory.
Should no SIZE be provided, it expands to the container width, less any margins, and is 24 pixels high.
Attributes:
VALUE (non inheritable) Can be set [initially] as {value,limit[,start[,run]]}, defaults to {0,100,0,true}. The value is a number between start and limit, controlling the current position / percentage complete. Setting to any value < length 4 automatically reactivates the internal timer, which automatically deactivates after displaying a value >= limit.
also ACTIVE, EXPAND, FONT, MARGIN, MINSIZE, MAXSIZE, TIP, SIZE, VISIBLE.
