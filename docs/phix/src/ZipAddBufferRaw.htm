ZipAddBufferRaw

Definition: include builtins\LiteZip.e

integer/object res = ZipAddBufferRaw(atom hzip, object pSrc, integer len=-1)
Description: Compress a single item into the previously specified memory buffer (no headers).

pSrc: from allocate(), or better yet a binary string, (say) get_text(GT_WHOLE_FILE+GT_BINARY).
len: the length of the (uncompressed) input in bytes, optional when string(pSrc).

Returns ZR_OK or a string error message. Personally I tend to declare res as integer and rely on the typecheck for debugging - failure should be pretty rare (bad params, called after ZipGetMemory(), unable to allocate an ~356 byte header, or buffer too small).
pwa/p2js: Not supported.
Comments: Do not try and re-use the same buffer multiple times, instead run ZipCreateBuffer() -> ZipAddBufferRaw() -> ZipGetMemory() -> ZipClose() for each item you wish to compress.
Example: 
include builtins\LiteZip.e

-- ucs is the uncompressed size
integer len = ucs+ceil(ucs/4096)+11
string buf = repeat(' ',len)
atom hbuf = ZipCreateBuffer(buf)

assert(ZipAddBufferRaw(hbuf,src[,ucs])=ZR_OK)

integer cs = ZipGetMemory(hbuf)
buf = buf[1..cs]
hbuf = ZipClose(hbuf)
