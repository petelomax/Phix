mem_copy

Definition: mem_copy(atom dst, atom src, integer len)
Description: Copy a block of len bytes of memory from address src to address dst.
pwa/p2js: Not supported.
Comments: The bytes of memory are copied correctly even if the block of memory at src overlaps with the block of memory at dst.

When they do no overlap, mem_copy(dst, src, len) is equivalent to poke(dst, peek({src,len})) but much faster. When they do overlap it is equivalent to a loop re-fetching each byte shortly after it may have been overwritten, causing a ripple effect, with said fetches almost always in the L1 cache (as in gap < 8K), essentially free.
Example: 
dest = allocate(50)
src = allocate(100)
poke(src, {1,2,3,4,5,6,7,8,9})
mem_copy(dest, src, 9)
Implementation: see builtins\VM\mem_copy.e (an autoinclude).
See Also: mem_set, peek, poke, allocate
