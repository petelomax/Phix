gSetFocus

Definition: include theGUI.e

gSetFocus(gdx id)
-- or --
gdx id = gGetFocus()
Description: Set keyboard focus to a specified interface element, or determine which if any control has said focus.

WARNING: only very lightly tested since the switch to canvas-based controls, may yet need significant work.

id: the control to set or (NULL if none) that has keyboard focus.
pwa/p2js: Partially supported, insofar as immediate display effects and re-routing of keyboard input to the specified control, but at the system level the browser strictly retains focus, and, for instance, there is none of the alt-tab handling of desktop/Phix, such as hiding/restoring focus display effects or auto-closing popups, specifically gMenus, gDatePicks, and gDropDowns. Likewise there may be cases where gGetFocus() returns NULL on desktop/Phix when the application is minimised or running in the background that a browser cannot realistically mimic.
Comments: Strange things may happen if attempted before anything has been displayed.

gGetFocus can sometimes return NULL under WinAPI, however that has not (yet) been observed under GTK.
Attempts to gSetFocus(NULL) are quietly ignored, for consistency, since GTK would never permit that.
