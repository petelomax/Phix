gLabel

Definition: include theGUI.e

gdx id = gLabel([object title=NULL, ] string attributes="", dword_seq args={})
Description: Creates a label interface element, which displays a static text string.

title: Text to be shown on the label, sets the TITLE attribute.
For more information on the attributes and args parameters see gSetAttributes().
This is a paranormalised function. (see technicalia)

Returns: the identifier of the created element.
pwa/p2js: Supported.
See Also: gImage, gButton
Example: 
-- demo\theGUI\gLabel.exw
include theGUI.e

gdx lbl = gLabel(`This is a label`),
    box = gHbox({lbl},`MARGIN=14`),
    dlg = gDialog(label,`gLabel`,`SIZE=240x80`)
gMainLoop(dlg)
Notes: Unlike some other GUI toolkits, there is no attempt to pony up a label into something it is not with an image or anything like that. Should you want to show the user an image, that belongs on a canvas mate.
Attributes:
ACTIVE An inactive label is drawn with the normal foreground colour greyscaled.
Possible values: "YES"/true, "NO"/false. Default: true.
LINK (not implemented) Default: false, true means use TITLE (shown underlined) else the (string) url to open when clicked.
Note it is shown in the default TG_BLACK unless you explictly set a different FGCLR, likewise should
you want hover effects you'll have to set up your own MOUSEMOVE and MOUSELEAVE handlers.
TITLE (non inheritable) Label's text. See here for mnemonic info. Can also be specified as {text,align}, where align is one of the constants from gDrawText, with the following anchor point effects, and the default behaviour being as per TG_E:


Note that multi-line labels, ie any embedded '\n' in text, ignore align and in fact use a TG_SE placement.
Aside: the latter and five other anchor points could technically be added, but quite frankly I fail to see the point,
and besides it is not exactly hard to draw text and whatever else wherever wanted on a simple canvas instead.
The natural size is large enough to include all the text in the selected font, even using multiple lines.
Note that EXPAND and/or gRedraw() after changing the title may be required for all characters to be shown.
also FONT, FGCLR, EXPAND, MARGIN, SIZE, TIP, VISIBLE.
Technicalia As this is a paranormalised function, and with no expectation that you should memorise this lot, except maybe "taa", you can assume that all of the following are potentially perfectly valid, with the fairly obvious restrictions that any parameters must be in strict taa-order, and no args without attributes: 

                        gLabel()
                        gLabel(title)
                        gLabel(attributes)              -- (see Note too)
                        gLabel(attributes, args)
                        gLabel(title, attributes)
                        gLabel(title, attributes, args) -- (the full set)

Note that in practice attributes is actually defined as sequence, but verified to be of the documented string type, after being repositioned via theGUI/paranormalise_taa().

Note too that gLabel(attributes) is distinguished from gLabel(title) by the presence of an '=' character, see here, and/or title being provided in {txt,align} form.
